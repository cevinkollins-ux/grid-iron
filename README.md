# Grid Iron

An NFL trivia grid for the **Dallas Cowboys** and the **Pittsburgh Steelers**. Pick a team at the top of the page (the colors switch to match). Each row is a well-known player from that team, each column is a category, and for each square you name a player who **played with that row's player** (on the team's roster in at least one of the same seasons) **and** fits the column.

The team is remembered in your browser. You can also link straight to one with `?team=dal` or `?team=pit`. Each team has its own Daily and its own saved progress.

Inspired by [The Reel Deal](../the-reel-deal), the movie version.

## Playing

Run the launcher, which serves the game locally and opens it in your browser:

```bash
python3 play.py
```

It uses http://localhost:8744/ (or the next free port if that one's taken) and works from any folder, e.g. `python3 ~/code/grid-iron/play.py`. Press Ctrl+C to stop. Add `--port 9000` to pick a port or `--no-browser` to skip opening a tab. Keep using the same port: your browser saves Daily progress per address, so a different port starts fresh.

You can also just open `index.html` directly. No sign-up or API key either way: each team's player database (about 1,500 players, 1960 to today) ships with the page: `data.js` for the Cowboys, `data-pit.js` for the Steelers.

- **Today's Daily**: the same grid for everyone each day (rolls over at midnight New York time). Progress is saved in your browser. Seeing the answers ends that day's Daily.
- **New grid**: a random grid, any time.
- **Share grid**: copies your score, a 🟩/⬜ board, and a link that rebuilds the exact grid.
- **See answers**: shows how many valid answers each square had, with a full list (rarest first).
- Click a row player for their Cowboys profile. Click a solved square's score badge for the breakdown.

## Scoring

50 points for a correct answer, plus 1–50 rarity points. Rarity depends on how many seasons the player spent in Dallas (one season scores 50; long-tenured players score low), and Hall of Famers, Ring of Honor members, and the row players themselves count as famous. Each player can be used once per grid.

## Categories

| Type | Examples |
|---|---|
| Position | Quarterback, Defensive line, Kicker/punter/snapper |
| Era | Cowboy in the 1990s |
| Rings | Won a Super Bowl with Dallas (1971, 1977, 1992, 1993, 1995 seasons) |
| Head coach | Played for Jimmy Johnson |
| Honors | Pro Football Hall of Famer, Ring of Honor |
| Career | Also played for the Eagles (any time in his career) |
| College | Played college ball at Texas |
| Draft | 1st-round pick, Drafted by Dallas, Went undrafted |
| Big season | 1,000-yard rushing season, 10-sack season (with Dallas, 1999 on) |
| Tenure | 10+ seasons in Dallas, Only 1 season in Dallas |
| Jersey | Wore #88 for Dallas |
| Teammate | Played with Troy Aikman |

The dealer picks 3 categories of different types, then 3 row players who each have at least 3 valid answers in every column, so every grid is solvable.

### "Can't verify" answers

Some data is missing for older players: college and jersey numbers for many 1960s Cowboys, draft records before 1980, and season stats before 1999. Rather than mark a possibly-correct answer wrong, the game says it can't verify it and lets you try someone else with no penalty. "See answers" only lists players the data confirms.

## Data

`data.js` and `data-pit.js` are generated by `scripts/build_data.py` (team settings such as coaches, Super Bowls, honors and row players are in its `TEAMS` table) from the free [nflverse](https://github.com/nflverse/nflverse-data) data releases:

- `rosters/roster_YYYY.csv`: every NFL roster since 1960 (all teams, so we know other teams a Cowboy played for). The 1960–62 Cowboys use the team code `COW`.
- `players/players.csv` and `draft_picks/draft_picks.csv`: college and draft info.
- `stats_player/stats_player_week_YYYY.csv.gz`: weekly stats since 1999, counted only for games played for Dallas.

Practice squad players are left out. Players are matched across files by NFL id, falling back to name + birth date for older rosters.

Maintained by hand in `scripts/build_data.py`:

- `HALL_OF_FAME` (through the 2026 class) and `RING_OF_HONOR` (24 members as of 2025; players only)
- `COACHES` (head coach by season), `SUPER_BOWL_WINS`
- `ANCHORS`: the ~100 players who can appear as rows
- `NAME_FIXES` and `ALIASES` (e.g. "Ed Jones" finds Too Tall Jones)

To refresh the data (e.g. weekly during the season):

```bash
python3 scripts/build_data.py --refresh
```

Downloads are cached in `data/raw/` (gitignored); `--refresh` re-downloads the current season and the player/draft tables.

## Known limitations

- "Played with" means on the same season's roster, so two players on the roster at different points in one season count as teammates.
- Stats categories only cover 1999 onward. Earlier stars (e.g. Tony Dorsett for 1,000-yard rushing) show as "can't verify" rather than wrong.
- Players without an NFL headshot show the NFL's generic silhouette.
- Daily grids depend on `data.js`; if the data is rebuilt mid-day, players who loaded different versions could get different Dailies. The grid code (e.g. `grid H43V`) makes that visible, and share links always rebuild the exact grid.
